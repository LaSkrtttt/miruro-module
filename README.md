# Miruro Shirox module

This module searches Miruro, lists episodes, and offers current English-subbed and English-dubbed HLS streams when available. English subtitle files are included with the soft-sub and dub options when Miruro provides them.

Upload `miruro.js` and `miruro.json` to the root of a public GitHub repository named `miruro-module`. Then add this manifest in Shirox:

`https://raw.githubusercontent.com/LaSkrtttt/miruro-module/main/miruro.json`
